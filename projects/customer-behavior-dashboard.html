Process

1
Questions
Defining the customer behavior problem

Started with questions around top customers, return frequency, average basket size, and customers who had not purchased recently.

2
SQL
Pre-calculating RFM segments

Used SQL to calculate recency, frequency, and monetary scores before loading the data into Power BI.

3
DAX
Building rolling-window measures

Created Sales Last 30 Days, Sales Last 90 Days, MoM Growth, Customer Count Last 30 Days, and Churned Customers measures.

4
Design
Segment overview and drill-through

Designed a segment overview page with distribution and KPI visuals, plus drill-through pages for customer-level purchase history.

Technical Artifacts
DAX snippet
Sales Last 30 Days = CALCULATE([Total Sales], DATESINPERIOD('Date'[Date], MAX('Date'[Date]), -30, DAY))
SQL snippet
SELECT customer_id, MAX(order_date) AS last_purchase
FROM sales
GROUP BY customer_id;
What I learned

Doing RFM segmentation in SQL before Power BI made the model simpler. DAX time intelligence also needs a proper Date table with no gaps.
