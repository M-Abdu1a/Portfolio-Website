SQL Data Preparation

These queries prepare the product, customer, review, engagement, and journey tables for reporting.

-- Price Categorization
  SELECT *,
    CASE
      WHEN Price < 50 THEN 'Low'
      WHEN Price BETWEEN 50 AND 200 THEN 'Medium'
      ELSE 'High'
    END AS PriceCategory
  FROM products
  ORDER BY PriceCategory ASC;

  -- Data Enrichment
  SELECT
    C.CustomerID,
    C.CustomerName,
    C.Email,
    C.Age,
    C.Gender,
    G.City,
    G.Country
  FROM customers AS C
  LEFT JOIN geography AS G
    ON C.GeographyID = G.GeographyID;

  -- Review Text Cleaning
  SELECT
    ReviewID,
    CustomerID,
    ProductID,
    ReviewDate,
    Rating,
    REPLACE(ReviewText, '  ', ' ') AS ReviewText
  FROM customer_reviews;

  -- Engagement Data Transformation
  SELECT
    EngagementID,
    ContentID,
    REPLACE(LOWER(ContentType), 'socialmedia', 'Social Media') AS ContentType,
    Likes,
    EngagementDate,
    CampaignID,
    ProductID,
    LEFT(ViewsClicksCombined, CHARINDEX('-', ViewsClicksCombined) - 1) AS Views,
    RIGHT(ViewsClicksCombined, LEN(ViewsClicksCombined) - CHARINDEX('-', ViewsClicksCombined)) AS Clicks
  FROM engagement_data
  WHERE ContentType != 'Newsletter';

  -- Duplicate Record Detection
  WITH DuplicateRecords AS (
    SELECT
      JourneyID,
      CustomerID,
      ProductID,
      VisitDate,
      Stage,
      Action,
      Duration,
      ROW_NUMBER() OVER (
        PARTITION BY CustomerID, ProductID, VisitDate, Stage, Action
        ORDER BY JourneyID
      ) AS row_num
    FROM customer_journey
  )
  SELECT *
  FROM DuplicateRecords
  WHERE row_num > 1;

  -- Deduplication and Missing-Value Handling
  SELECT
    JourneyID,
    CustomerID,
    ProductID,
    VisitDate,
    Stage,
    Action,
    COALESCE(Duration, avg_duration) AS Duration
  FROM (
    SELECT
      JourneyID,
      CustomerID,
      ProductID,
      VisitDate,
      Stage,
      Action,
      Duration,
      AVG(Duration) OVER (PARTITION BY VisitDate) AS avg_duration,
      ROW_NUMBER() OVER (
        PARTITION BY CustomerID, ProductID, VisitDate, Stage, Action
        ORDER BY JourneyID
      ) AS row_num
    FROM customer_journey
  ) AS Subquery
  WHERE row_num = 1;
Python Sentiment Analysis

This script scores review text and combines the result with the review rating.

import pandas as pd
  from sqlalchemy import create_engine
  import urllib
  import nltk
  from nltk.sentiment.vader import SentimentIntensityAnalyzer

  nltk.download('vader_lexicon')

  def fetch_data_from_sql():
    server = r"Abdullah\SQLEXPRESS"
    database = "PortfolioProject_MarketingAnalytics"

    conn_str = (
      f"Driver={{SQL Server}};"
      f"Server={server};"
      f"Database={database};"
      f"Trusted_Connection=yes;"
    )

    params = urllib.parse.quote_plus(conn_str)
    engine = create_engine(f"mssql+pyodbc:///?odbc_connect={params}")
    query = "SELECT ReviewID, CustomerID, ProductID, ReviewDate, Rating, ReviewText FROM PortfolioProject_MarketingAnalytics.dbo.customer_reviews"

    with engine.connect() as conn:
      df = pd.read_sql(query, conn)

    return df

  customer_reviews_df = fetch_data_from_sql()
  sia = SentimentIntensityAnalyzer()

  def calculate_sentiment(review):
    if pd.isna(review):
      return 0.0
    return sia.polarity_scores(str(review))['compound']

  def categorize_sentiment(score, rating):
    if score > 0.05:
      if rating >= 4:
        return 'Positive'
      elif rating == 3:
        return 'Mixed Positive'
      else:
        return 'Mixed Negative'
    elif score < -0.05:
      if rating <= 2:
        return 'Negative'
      elif rating == 3:
        return 'Mixed Negative'
      else:
        return 'Mixed Positive'
    else:
      if rating >= 4:
        return 'Positive'
      elif rating <= 2:
        return 'Negative'
      else:
        return 'Neutral'

  def sentiment_bucket(score):
    if score >= 0.5:
      return '0.5 to 1.0'
    elif 0.0 <= score < 0.5:
      return '0.0 to 0.49'
    elif -0.5 <= score < 0.0:
      return '-0.49 to 0.0'
    else:
      return '-1.0 to -0.5'

  customer_reviews_df['SentimentScore'] = customer_reviews_df['ReviewText'].apply(calculate_sentiment)
  customer_reviews_df['SentimentCategory'] = customer_reviews_df.apply(
    lambda row: categorize_sentiment(row['SentimentScore'], row['Rating']), axis=1)
  customer_reviews_df['SentimentBucket'] = customer_reviews_df['SentimentScore'].apply(sentiment_bucket)

  print(customer_reviews_df.head())
  customer_reviews_df.to_csv('fact_customer_reviews_with_sentiment.csv', index=False)

Project breakdown

1
Business Context
Understanding the e-commerce performance crisis

Shop Easy, an online retailer, faced a critical business challenge: declining customer engagement and conversion rates despite increasing marketing expenses. Stakeholders needed clear answers about where revenue was leaking in the customer journey and which marketing channels were delivering ROI.

2
Data Extraction & Cleaning
Cleaning the tables used for analysis

Used SQL to join clickstream, engagement, transaction, customer, and product data from multiple sources. Cleaned duplicate records, handled missing values, and created structured datasets for downstream analysis. Prepared fact tables (Customer Journey, Engagement, Reviews) and dimension tables (Customers, Geography, Products).

3
Sentiment Analysis
Turning review text into usable fields

Applied Natural Language Processing (NLP) techniques in Python to analyze customer reviews and social media comments. Scored sentiment as positive, neutral, or negative to surface recurring pain points in product quality, delivery, and customer service. Transformed unstructured text into measurable customer satisfaction metrics.

4
Data Modeling
Connecting facts and dimensions for reporting

Structured the cleaned data into fact and dimension tables, connected customer, product, geography, engagement, journey, and review entities, and prepared consistent measures for analysis in Power BI.

5
Dashboard Design
Building the Power BI report

Designed interactive dashboards to track Conversion Rate, Customer Engagement Rate, Average Order Value (AOV), and Customer Feedback Score. Built conversion funnel visualizations to identify primary drop-off stages, channel-level performance heatmaps to isolate low-ROI campaigns, and sentiment trend charts to reveal customer satisfaction patterns.

More dashboard views
6
Key Findings & Insights
Finding the main conversion and channel issues

Analysis revealed customer drop-off concentrated in the cart checkout phase (43% abandonment) and low-performing channels (social media ads had 2.3x lower conversion than organic). Sentiment analysis showed delivery delays and product quality inconsistencies were primary friction points. These insights directly informed channel reallocations and operational improvements.
