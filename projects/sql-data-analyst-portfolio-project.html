Project breakdown

1
Changes Over Time
Analysing trends and changes over time

Started by comparing business metrics across time periods to identify growth, decline, and meaningful changes in performance.

2
Cumulative Analysis
Building cumulative metrics

Used cumulative calculations to understand how performance built over time and to make long-term progress easier to evaluate.

3
Performance Analysis
Comparing performance against benchmarks

Compared current results with previous periods and target values to identify strong and weak performers.

4
Part To Whole
Measuring contribution to the total

Analysed how categories, products, and other business segments contributed to overall performance.

5
Data Segmentation
Segmenting data for deeper insight

Grouped records into meaningful segments so patterns could be compared across customer, product, and performance profiles.

6
Customer Report
Building the customer report

Created a customer-focused report that brings together customer behaviour, purchase patterns, and business performance measures.

7
Product Report
Building the product report

Built a product report to compare product performance, identify top and underperforming products, and support more informed decisions.

8
GitHub
Publishing the project in GitHub

Committed the SQL analysis and project work to GitHub so the workflow, queries, and reporting process remain available as a portfolio project.

9
Database Exploration
Exploring the database structure

Inspected the database structure and available tables to understand the starting point for the analysis.

10
Dimensions Exploration
Understanding the dimensions

Explored the dimension tables and their attributes to establish the business context behind the records.

11
Date Exploration
Validating the date context

Reviewed date fields and time coverage to make sure trend, period, and cumulative analysis would be reliable.

12
Measures Exploration
Defining the core measures

Identified and reviewed the core measures needed to compare revenue, quantity, contribution, and business performance.

13
Magnitude Analysis
Measuring the size of the business

Used magnitude analysis to understand the scale of products, customers, and key measures across the dataset.

14
Ranking Analysis
Ranking products and customers

Ranked products and customers to surface the strongest contributors and create a clear prioritisation for decision-making.
